## 结论与范围 {#goal}

PPO 的 value[b] 提议 AUC 为 0.573 [0.514, 0.633]，最终成功 AUC 为 0.872 [0.854, 0.889]；U1 的均值相对正常实际成功率差为 -0.107 [-0.181, -0.028]。 SAO 的 value[b] 提议 AUC 为 0.553 [0.487, 0.620]，最终成功 AUC 为 0.830 [0.807, 0.851]；U1 的均值相对正常实际成功率差为 -0.144 [-0.215, -0.067]。

**全量 forward 已完成；以下为观测结果，尚待 Claude 审阅。**

目标是判断用户回复前的 $U$ 能否提供 agent 提议质量信号，并比较 PPO 与 SAO。AUC 的正类分别为文本提议全覆盖和最终 reward=1；分数方向固定为越大越好。

## 估计口径 {#decisions}

保留 brief 实际列出的全部五种估计：`U_b=value[b]`、`U_bm1=value[b−1]`、`U_last8`、`U_last32`、`U_all`。均值区间分别为 `[max(a,b−7),b]`、`[max(a,b−31),b]`、`[a,b]`，包含生成 EOS；没有重新 tokenize。$V_t=value[a-1]$，内部 $V_{next}=value[next_a-1]$。

确认规则沿用 infra 审计的 ASK 与 DONE/STRONGASK 条件。提议标签沿用 pending5 参数叶子值文本覆盖：只看当前边界前最多 5 条消息中的 assistant 文本，检查 gold 中尚未执行的所有 write 参数。尚未执行由该边界之前的 tool calls 判断，并沿用 tau2 compare_args 比较语义；不使用 episode 结束时的 action_match。无待执行 write 的确认边界不标正确/错误，仍进入最终成功 AUC。

U1 需要 is_u1_rule 命中终止边界且仍有待执行 gold write；单独保留 u1_rule 字段，便于检查无害命中。正常对照要求正确提议、非终止且下一条用户回复不含任何终止标记。

## 影响结论的限制 {#scope}

这是训练任务上的 in-sample 检查：两个 critic checkpoint 各自对附近 epoch 的 rollout 做 forward，不能当作未见任务泛化。PPO 与 SAO 的 checkpoint 年龄、训练轮数和策略分布不同；差异不能单独归因于算法或 attention freeze。

文本覆盖是提议与 gold 参数一致的代理：既不验证 tool name/后续执行，也不保证自然语言断言或 DB 终态满足；前 5 条消息可能携带之前提到但当前未提议的参数，多目标任务也可能因尚未讨论的子目标被标错误。因此 AUC 说明对该标签的区分，不能直接等同于 agent 完全做对。

U1 的实际 R 已受提前 STOP 污染，正常对照成功率不能证明 U1 反事实结果。共享 task 标准化减少题目混杂，但不消除对话状态和后续策略差异。单类或样本过少时区间不可估计；没有将缺失项填成 0.5。
