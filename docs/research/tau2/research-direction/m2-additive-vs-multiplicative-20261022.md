# M2 重新推导：估计 $a$ 还是估计 $\varepsilon$，乘法还是加法

2026-10-22。起因是当天与导师的讨论（飞书「10月22日讨论记录」）：$A=a+\varepsilon$ 的拆解没有问题，但 M2 假设 $a$ 与
$\varepsilon$ 独立，这一点不确定；$w_u$ 的作用也没讲清楚。导师建议直接估计 $\varepsilon$，做加法修正。本文回答三个问题：
两种估计有什么区别；M2 到底要解决什么；哪种设计更有依据、更好实现。写法参照 Score Centering（2609.20807）：先把期望梯度
拆开，指出哪一项是用户带来的，再看修正是否恰好消掉这一项。

## 结论

1. **"估计 $a$"和"估计
   $\varepsilon$"作为点估计是同一件事**：$\hat a=A-\hat\varepsilon$。真正的区别在估计量的形式和它用到的信息。现在的 M2
   是乘法，$\hat a=w_uA$，只用到剧本层面的方差统计；导师的建议是加法，$\hat a=A-\hat\varepsilon$。导师没有指定
   $\hat\varepsilon$ 的粒度，第 4.2 节按"$\hat\varepsilon$ 什么时候能算出来"列出可选的形式。
1. **M2 现在的"作用"和"推导"对不上。** 文档说 M2 处理"可预测的用户不可靠"，靠的是改目标；但 $\tau/(\tau+\sigma_u^2)$
   的推导是在噪声下估计 $a$，属于降方差。可是对同一剧本乘一个常数，不改变这个剧本内的信噪比，所以 M2 实际上只是按剧本设学习率，降不了方差。
1. **加法修正要么只是 baseline，要么由 critic 的 value 变化构成。** $\hat\varepsilon$ 在 episode
   开始前就能算出来时，它只是 baseline（M1 的范围），不影响期望梯度。要去掉这一次用户实际造成的影响，$\hat\varepsilon$
   必须用到用户实际说了什么；在不加检测器的约束下，能用的只有 critic 的 value 变化。按用户回合取 $\hat\varepsilon$ 这一种（第 4.2 节
   C）就是之前预实验已经放弃的 β。它的无偏条件可以检验：critic 在 agent→用户边界上校准，不需要假设 $a\perp\varepsilon$。
1. **加法修正只能去掉"实现出来的用户噪声"，去不掉"可预测的用户不可靠"。** 后者在不加检测器的约束下，任何方法都没有标签可用。论文要先选定 M2 针对哪一种。

## 1 记号

| 记号         | 含义                                                                            |
| ------------ | ------------------------------------------------------------------------------- |
| $t$          | agent 的某个 token；$s_t=\nabla_\theta\log\pi_\theta(a_t\mid h_t)$ 是它的 score |
| $k$          | 第 $k$ 个 agent→用户边界（agent 一轮说完的 `<\|im_end\|>`）                     |
| $H_k$        | 到边界 $k$ 为止的全部历史，包括 agent 这一轮的所有动作                          |
| $U_k=V(H_k)$ | 边界 $k$ 上 critic 的 value：agent 说完、用户还没回复                           |
| $V_k$        | 第 $k$ 轮 agent 开始说话前的 value；$V_{K+1}:=R$                                |
| $z$          | 用户剧本（M1 的 critic 读它）                                                   |

设定与现在的训练一致：$\gamma=\lambda=1$，只有结局 reward $R\in\{0,1\}$，所以 $A_t=R-V(h_t)$。

## 2 把 advantage 按回合拆开

$\gamma=\lambda=1$ 时 advantage 可以按回合逐段相加。对第 $j$ 轮里的 token $t$：

$$
A_t=R-V(h_t)=\underbrace{\big(U_j-V(h_t)\big)+\sum_{k>j}\big(U_k-V_k\big)}_{\text{agent 段}}
\;+\;\underbrace{\sum_{k\ge j}\big(V_{k+1}-U_k\big)}_{\text{用户段 }D_k}
$$

$D_k=V_{k+1}-U_k$ 是第 $k$ 次用户回复（含用户自己的工具调用）让 value 变了多少，也就是 critic
在用户回合上"没料到"的部分。这一步只是恒等变形，没有任何假设。

用户的影响分三种，它们落在上式的不同位置：

| 成分                        | 例子                        | 在哪一项里                                     |
| --------------------------- | --------------------------- | ---------------------------------------------- |
| (i) 用户对 agent 的正常反应 | agent 报错价格，用户拒绝    | critic 准时在 $U_k$ 里；不准时一部分留在 $D_k$ |
| (ii) 可预测的用户不可靠     | 一问"确认吗"就容易 STOP     | 期望部分在 $U_k$ 里（agent 段）                |
| (iii) 实现出来的用户噪声    | 这一次碰巧 STOP、编造了事实 | $D_k$                                          |

## 3 哪一项只贡献方差

对 $k\ge j$，$s_t$ 由 $H_k$ 决定，所以

$$
\mathbb{E}[D_k\,s_t]=\mathbb{E}\big[s_t\,\mathbb{E}[D_k\mid H_k]\big].
$$

如果 critic 在边界上校准，即 $U_k=\mathbb{E}[V_{k+1}\mid H_k]$，那么
$\mathbb{E}[D_k\mid H_k]=0$，用户段对期望梯度的贡献为零，只贡献方差。这里不需要 $a\perp\varepsilon$：用户的反应可以完全取决于
agent 说了什么，只要 critic 在 $U_k$ 里已经把这种依赖算进去就行。

critic 不准时，用户段带来的期望梯度是

$$
\mathbb{E}[D_k\,s_t]=\mathbb{E}\big[(U_k^{\text{true}}-U_k)\,s_t\big],\qquad U_k^{\text{true}}=\mathbb{E}[V_{k+1}\mid H_k],
$$

也就是 critic 在边界上的误差中与 agent 动作相关的那部分。

由此得到两点：

- **成分 (iii) 是纯噪声**，期望为零，只增加方差。
- **成分 (ii) 是真信号**：它在 $U_k$ 里，属于"在这个用户下的成功率"。agent
  学会少问确认，是在原目标下正确的梯度。要不要学它是目标选择，不是噪声问题。这与文档 M1 一节的表述一致。

## 4 两种修正分别做了什么

### 4.1 现在的 M2：乘法，按剧本

$$
g=\sum_{\text{episode}}w_u\sum_tA_t\,s_t
$$

- **期望**：$\sum_uw_u\nabla J_u$，即按剧本改了目标的权重。$w_u$ 只用过去 epoch 的记录，在剧本内仍然无偏。
- **方差**：同一剧本内 $w_u$ 是常数，信号和噪声同比例缩放，信噪比不变。$\tau/(\tau+\sigma_u^2)$ 是"只看到标量 $A$ 时对 $a$
  的最好线性估计"，但它不改变剧本内的信噪比，所以不能拿来论证"降方差"。它在跨剧本之间做的事，是让噪声大的剧本少算一些。
- **它能否针对成分 (ii)、(iii)**：$w_u$ 不区分一条 episode 里哪里出了问题，(i)(ii)(iii) 和 agent
  自己的成败一起被缩小。它有用的前提是 $\hat\sigma_u^2$ 主要反映用户。649 的离线检验在 DeepSeek
  用户下否定了这一点：$\hat\sigma_u^2$ 与非 U1 失败率的相关（Airline 0.36、Retail 0.73）高于与 U1
  比例的相关（0.22、0.47）。
- **新发现的问题**：10-21 的 GPU 验证里，第 1 轮 critic 的 value head 还是初始值，所有 $U$ 都等于 0.6205，所以
  $X=R-U$ 只是 $R$ 减一个常数，$s_u^2$ 只能取 0 或 0.5。也就是说，M2 早期的权重实际上是按 $\mathrm{Var}(R)$
  算的，正是文档说不该用的量。

### 4.2 导师的建议：加法，$\hat\varepsilon$ 可以取什么

导师的建议是估计 $\varepsilon$ 并减掉，没有指定粒度。下面按 $\hat\varepsilon$ 什么时候能算出来，分三种。这个分法是本文的整理，不是导师的说法。

**A. episode 开始前就能算出来**（只依赖剧本 $u$ 或 $z$，例如剧本过去 $X$ 的均值）。这时
$\mathbb{E}[\hat\varepsilon\,s_t]=\hat\varepsilon\,\mathbb{E}[s_t]=0$，它只是 baseline，属于 M1
的范围：不改变期望梯度，也去不掉这一次用户实际造成的影响。

**B. episode 结束后，整条 episode 一个数**（例如只取终止边界上的 $R-U_K$，对所有 agent token 减同一个量）。它是 C
只保留最后一个用户回合的特例，无偏条件相同。

**C. 每个用户回合一个数。** 在第 2 节的分解下，"用户带来的部分"有一个直接的估计：

$$
A_t'=A_t-\sum_{k\ge j}c_k\,D_k,\qquad c_k\in[0,1].
$$

- **期望**：critic 在边界上校准时，$\mathbb{E}[D_k\,s_t]=0$，减掉后期望梯度不变，原目标下无偏。不校准时的偏差是
  $\sum_kc_k\,\mathbb{E}[(U_k^{\text{true}}-U_k)s_t]$，与 GAE 取 $\lambda<1$
  的偏差同类，只是只作用在用户回合上。
- **方差**：去掉的是 $\mathrm{Var}(\sum_kc_kD_k)$ 以及它与 agent 段的协方差。用户越不稳定，去掉的越多。
- **为什么需要 M1**：成分 (i) 是否混在 $D_k$ 里，取决于 critic 能否预见用户的正常反应。用户按剧本行事且 T=0 时，正常反应几乎由剧本和
  agent 的话决定，读剧本的 critic 能提前算进 $U_k$，于是 $D_k$ 里剩下的主要是 (iii)。649 的数据支持这一点：中间用户段
  $V_{k+1}-U_k$ 的标准差，带剧本的 critic 是 0.047，不带的是 0.066，均值都接近 0（−0.002、+0.005）。
- **粒度**：修正落在每个用户回合上，作用于这一回合之前的所有 agent token。

**除了 A–C 还有没有别的选择。** 要去掉这一次用户实际造成的影响，$\hat\varepsilon$ 必须是对话内容的函数，并且能把用户的部分和 agent
的部分分开。不加检测器、judge 或额外模型时，训练里唯一学到"这段对话会怎样结束"的量就是 critic，所以 B、C 都是 critic value
变化的组合。如果要找不是 critic 的 $\hat\varepsilon$（例如另训一个"假如用户按剧本走，结局会怎样"的
value），就需要额外的模型或标签，超出了导师的约束。

### 4.3 与 Score Centering 的对应，以及不对应的地方

结构相同：Score Centering 拿加法修正与乘法的 importance sampling
对比，指出乘法项是随机的、会放大方差，加法项可以精确消掉要去掉的那一项。这里也是加法对乘法。

不同之处在无偏的机制：Score Centering 的修正项在采样 token 之前就由前缀决定，它的期望在同一个分布下天然为零；我们的 $D_k$ 依赖 agent
动作之后的用户回复，只有在 critic 校准时条件期望才为零。论文里要把这个条件写明，不能说"和 Score Centering 一样精确"。

## 5 与旧 β 的关系

取 $c_k\equiv1-\beta$ 时，4.2 节 C 的式子与预实验后已经放弃的 β 方案（`areal/trainer/ppo/gae.py` 里
`delta - (1 - beta) * user_segment`）是同一个公式。也就是说，导师的加法方向在不加检测器时，具体落地会回到 B 或 C，即回到 β
这一族。这一点要先和导师说清楚，避免把旧方法换个名字再提一遍。

当初放弃 β 的依据是 649 的分解：β 从 1 降到 0 时，去掉的主要是非 U1 失败的惩罚和成功的 credit，U1 只占 21%。按第 3
节，这个判据回答的不是"有没有偏"：它按结局（U1 / 非 U1 失败 / 成功）分组，失败组的 $R-U$
必然为负，这是按结果筛选造成的。有没有偏要看按历史分组的校准：$\mathbb{E}[D_k\mid U_k\text{ 分箱}]\approx0$。所以旧结论"统一 β
误伤为主"不能直接否定加法修正，但也没有证明它有效。是否重新启用，由你和导师决定。

如果不想用统一的 $c_k$，又不允许加检测器，$c_k$ 只能来自 critic 自身的量。例如按边界的历史校准误差选择
$c_k$：校准好的地方多减，校准差的地方少减。这一点还没有推导完。

## 6 已知限制

- **U3 不在 $D_k$ 里**：10-21 的 U3 检验中，649 的 critic 在 U3 那句用户回复前后 value 几乎不变（+0.001
  \[−0.023, +0.024\]）。这时 $D_k\approx0$，加法修正什么也去不掉，惩罚会落到之后的 agent 段上。这个 critic 是在
  DeepSeek 用户下训练的，那里几乎没有 U3；在 Qwen3.5-4B 用户下训练的 critic 能否在 U3 处压低 value，要用 method run 的
  critic 复查。
- **成分 (ii) 无法处理**：在不加检测器或 judge 的约束下，加法修正去不掉 (ii)；乘法 M2 只有在 $\hat\sigma_u^2$
  真的反映用户时才算部分处理了它，而 DeepSeek 下的检验是否定的。
- **critic 的校准是前提**：训练早期 critic 不准，加法修正会带来 $\lambda<1$ 式的偏差。早期是否需要 $c_k=0$
  预热，要看校准随训练步的变化。

## 7 用已有数据能做的判别

都不需要新的基础设施，用 run 3（680，标准 critic）和 method run 的训练 rollout 与 checkpoint 离线完成：

1. **边界校准**：按 $U_k$ 分箱和按剧本，看 $\mathbb{E}[D_k]$ 是否接近 0；分别比较带剧本和不带剧本的
   critic。这是加法修正无偏的直接检验。
1. **用户段的方差占比**：$\mathrm{Var}(\sum_kD_k)/\mathrm{Var}(A)$，按 domain
   和用户模拟器分组。占比小，则加法修正没有必要。
1. **$D_k$ 是否集中在用户出错的回合**：用已有的 U1/U3 人工标签，比较出错回合和正常回合的 $|D_k|$。这一项决定 M2 的作用能否写成"把用户错误从
   agent 的 credit 里拿掉"。

## 8 对正在排队实验的影响

682（privileged critic + 乘法 M2，β=1）约 24 小时后才会启动。如果方法转向加法修正，682
的设计需要重新考虑。在它启动前还有两项已提出的待定事项：撞到消息上限的 episode 是否进入 M2 的记录；早期 critic 退化导致权重相当于按
$\mathrm{Var}(R)$ 计算的问题。队列没有改动。
