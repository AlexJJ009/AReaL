# 649 带剧本 critic 的 case study：EV 更高从哪来，对 β 意味着什么

2026-10-21。问题：649（PPO + 读用户剧本的 critic，β=1）的 critic 是否比标准 critic 评估得更好；用户回复两侧的 value
有没有变化，能否为 per-boundary β 提供证据。Codex 做分析（pueue 657 CPU、659 修复与 β 分析、660 GPU 前向 8 卡 11
分钟），Claude 复核。判据在 GPU 结果产生前写进 `preregistration.md`。

产物：`phai:_artifacts/AReaL/codex-sao-math/tau2-privileged-critic-case-study-20261021/`（`REPORT.md`
是第一期， `phase2_analysis/beta_tables.md`、`summary.json` 是第二期）。

## 设置

- 训练日志：649、基线 v3（+ext，标准 critic，β=1，DeepSeek 官方用户）、631（标准 critic，β=0.5，火山 260910）的逐步统计。
- GPU 前向：649 最后 4 个 epoch 的训练 rollout（2988 条 episode、13580 个边界，全部与轨迹匹配，无排除）。同一批数据分别给 649
  critic（`globalstep119`，带剧本前缀）和 v3 critic（`globalstep119`，不带）前向，数据相同、只换 critic。
- 符号：$V_t$ 是 agent 最后一轮开始前的 value，$U$ 是 agent→用户边界上的 value（`value[b]`），$R$ 是最终
  reward。agent 段 $U-V_t$，用户段 $R-U$（终止边界）或 $V_{k+1}-U$（中间边界）。

## 结论

1. **EV 更高，而且不只是"知道题目难度"。** 晚期（100–120 步）训练 EV：649 0.458，v3 0.348，631 0.351；649−v3 =
   +0.110 \[0.064, 0.156\]（按步 bootstrap）。在同一批 649 rollout 上，同一道题内成功和失败能不能分开：

   | 位置                    | 带剧本 pair AUC | 标准 pair AUC | 带剧本 题内残差 EV | 标准 题内残差 EV |
   | ----------------------- | --------------- | ------------- | ------------------ | ---------------- |
   | 第一个 agent token 前   | 0.548           | 0.489         | 0.002              | −0.006           |
   | 对话中间                | 0.634           | 0.536         | 0.070              | 0.012            |
   | 最后一个 agent→用户边界 | 0.938           | 0.758         | 0.508              | 0.204            |

   对话开头两者都分不出（同一道题的开头状态本来一样），越往后差距越大。所以提升来自对对话状态的判断，不只是题目级先验。

   注意：v3 critic 是在 v3 自己的 rollout 上训练的，放到 649 的数据上有分布偏移；在自己数据上它的最后边界 AUC 是 0.833，残差 EV
   0.248。649 critic 是在这批数据上训练的（in-sample）。按两者各自 in-sample 比较，差距是 0.938 对
   0.833，仍然明显，但小于上表。

1. **带剧本 critic 让终止处的"用户段意外"更集中在用户错误上，这是对 β 的支持证据。** 失败信号几乎全部落在最后一次用户回复上（$R-U$），agent
   段很小，两个 critic 都是这样。区别在于非 U1 失败（agent 自己做错）：

   | 终止边界                     | n    | 带剧本 $R-U$ | 标准 $R-U$ |
   | ---------------------------- | ---- | ------------ | ---------- |
   | 失败且是 U1（用户提前 STOP） | 60   | −0.734       | −0.682     |
   | 失败但不是 U1                | 620  | −0.262       | −0.455     |
   | 成功                         | 2286 | +0.057       | +0.179     |

   带剧本 critic 对 agent 做错的 episode 提前就把 value 压低了，到结算时剩下的意外小；对 U1，用户提前 STOP
   事先看不出来，两者意外差不多。β 在 U1 上相对非 U1 失败多去掉的惩罚：带剧本 0.472 \[0.402, 0.540\]，标准 0.226 \[0.166,
   0.290\]；两者之差 +0.246 \[0.198, 0.293\]，满足预登记的"带剧本 critic 更能把 U1 分离出来"。

1. **用户回复处的 value 没有出现"起伏或下降"，这个假设不成立。** 中间用户段 $V_{k+1}-U$：带剧本均值 −0.002、sd 0.047，标准
   +0.005、sd 0.066，带剧本的反而更平。U1 STOP 之前的那次用户回复上，带剧本的 value 是轻微上升（+0.020 \[0.000,
   0.044\]），标准是轻微下降（−0.022）；按预登记，这一项属于"反对"。合理的解释是 U1 之前用户通常在确认 agent 的提议，带剧本 critic
   因此更乐观，偏离发生在最后那一句 STOP 里。

1. **统一 β（不用检测器）在带剧本 critic 下误伤小得多，但仍以误伤为主。** 导师不接受额外的检测器或 judge（2026-10-21），β
   只能对所有终止用户段统一打折。把 β 从 1 降到 0 时，各组被去掉的量（episode 数 × 每条的平均量）：

   | critic | U1 惩罚 | 非 U1 失败惩罚 | 成功的 credit | U1 占失败惩罚的比例 |
   | ------ | ------- | -------------- | ------------- | ------------------- |
   | 带剧本 | 44      | 162            | 130           | 21%                 |
   | 标准   | 41      | 282            | 410           | 13%                 |

   带剧本 critic 下，被误伤的部分（非 U1 失败的惩罚加成功的 credit）是 292，标准 critic 下是 692。也就是说，带剧本 critic 把
   agent 自己的成败提前算进了 value，统一 β 去掉的主要是剩下的意外，其中用户错误的比例更高。β 在训练里是否有益要看 2×2（带剧本 / 标准 × β=0.5
   / 1）。

## 局限

- 649 只有一个 run；v3 的训练用户后端、并发都不同。前向比较的是两个已训练好的 critic，不是受控训练。
- U1 由规则标出（失败门控），只有 60 个；"U1 前的那次回复"只是时间上的代理，没有逐句标注。
- 前向用的是训练题上的 rollout，属于 in-sample；没有 held-out 检查。
- 训练日志里 v3 的 critic mask 不含用户边界位置，另两个含；去掉这些位置后 EV 几乎不变（649 0.458019 → 0.458012）。

## 补充：按用户剧本的可靠度加权（2026-10-21，pueue 662–664）

想法：τ² 每道题对应一个用户剧本 $u$。跨 epoch 记下每个剧本终止处的意外 $R-U$，用过去的记录估计 $\hat\sigma_u^2$（向 domain
均值收缩），actor loss 乘 $w_u=\tau/(\tau+\hat\sigma_u^2)$，batch 内归一化到均值 1。不需要检测器或额外的
LLM。只有当剧本噪声是稳定的属性、并且噪声大的剧本是用户出错的剧本时，这样做才有用。

检验：649 全部 20 个 epoch 的训练 rollout（14,866 条可用 episode，747 个剧本，每个约 20 条），用 649 最终 critic
前向（8 卡 22 分钟）。判据在 GPU 结果之前写进
`preregistration.md`。产物：`phai:_artifacts/AReaL/codex-sao-math/tau2-user-reliability-weight-20261021/`。

结论：**不成立，按剧本加权在 649 上没有可以作用的地方。**

1. **剧本噪声是稳定的属性。** 奇数和偶数 epoch 各估一次，Spearman：Airline 0.62 \[0.54, 0.68\]，Retail 0.55
   \[0.46, 0.63\]。
1. **但它反映的主要是 agent 的成败，不是用户。** $\hat\sigma_u^2$ 与 U1 比例的相关是 Airline 0.22、Retail 0.47，与非
   U1 失败比例的相关是 0.36、0.73，后者更强；两者之差的 CI 都在 0 以下（Airline −0.14 \[−0.28, −0.003\]，Retail
   −0.26 \[−0.36, −0.16\]）。直接用 $\operatorname{Var}(R)$ 更差。Claude 用 `scenarios.jsonl`
   复算了这几个相关，一致。
1. **按训练顺序模拟（只用过去 epoch），权重去掉的 U1 惩罚比例反而最小**：U1 9.9%，非 U1 失败 15.6%，成功的 credit 14.2%（两个
   domain 都是这样）。对照：统一 β 从 1 降到 0 几乎全部去掉三者（105% / 96% / 76%）。

解释：在 DeepSeek 用户下，U1 只占约 2% 的 episode，分散在 197 个剧本里（Airline 90 / 410，Retail 107 /
337），没有集中在少数"不可靠用户"上。一个剧本结果波动大，主要是因为 agent 在这道题上时成时败，这恰好是学习信号所在。

局限：critic 是见过这些 rollout 的最终 critic（偏乐观，所以这里的否定结论更可靠）；只有 U1 一种用户错误标签；只有 DeepSeek 用户。Qwen
用户出错更多，可以用 run 3 的 rollout 复查。
