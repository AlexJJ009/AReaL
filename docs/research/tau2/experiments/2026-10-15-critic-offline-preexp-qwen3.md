## 1. 目的

下一步要在 Qwen3-4B-Instruct-2507 上跑 PPO 和 SAO。两者的 critic 都先做 critic-only 训练（K2），再交给
RL。本实验在冻结的 Qwen3 骨干网络特征上做离线分析，定 K2 的设置：

- Qwen3 的特征里有多少能线性预测成败的信号（只训 head 能达到的上限）；
- head 用多大的学习率；
- 用最后一层还是中间层更合适；
- 480 的 critic-only 训练有没有改善骨干网络的特征。

Qwen3.5 预实验到 E3 为止的结果：冻结的最后一层特征上，Airline 的 ridge 探针 EV 约 0.09（区间含 0），Retail 约 0；lr 5e-6
时 head 几乎不动。本实验用同样的方法在 Qwen3 上重做最关键的四项。

不调用 API，不启动 SGLang 和用户模拟器。特征提取用 GPU；其余实验可以用 GPU 或 CPU，由实现决定。

## 2. 背景

- 480（`critic-instruct-formal-v1`）：Qwen3-4B-Instruct 的 critic-only 训练。actor
  固定，temperature 1；747 道训练题每题每 epoch 1 条，batch 16，2 个 epoch 共 94 步；critic lr 5e-6，冻结
  attention，MLP、embedding、norm、head 都训练。head 是 Qwen3 `AutoModelForTokenClassification`
  的默认初始化（权重随机、bias 为 0），不是 ADR 0012 的初始化。验证 EV 在第 30 步之后一直在 −0.04 到 +0.01。
- 480 的训练顺序没有打乱：每个 epoch 先跑 pack 的 648 题，官方 fixed train 99 题排在最后约 6 步。这是缺陷，已在
  `codex/critic-shuffle` 修复；本实验复现 480 时按它实际的顺序，其余模拟打乱。
- K2 计划的 head 初始化：$w=0$，$b$ = 480 训练 rollout 的平均成功率 927/1494 = 0.6205（ADR 0012）。
- Qwen3.5 预实验 E3 用了约 4 小时，原因是每一步模拟都从磁盘重新读特征分片（累计读了约 780 GB），不是计算量大。本实验的特征一次载入内存或 GPU。

## 5. 公共设置

### 5.1 数据池

执行前由 Codex 核对并写出清单（同 Qwen3.5 预实验的数据核对）：条数、每题条数、成败分布、`input_ids`/`loss_mask`/`reward`
是否齐全、超出预算或 infra 异常的轨迹，以及训练题与验证题不重叠。清单写 sha256，所有实验只读这份清单。

预期规模：训练 747 题各 2 条，Airline 820 条、Retail 674 条，成功 927 条；验证 60 条（Airline 20、Retail
40）。以清单为准。

验证集只有 60 条、每题 1 条，比 Qwen3.5 的 120 条少一半，区间会更宽。结论按这个限制写。

480 的验证用 fixed-v2 test，PPO 的评测用 fixed-v3 test；两者在 7 道题上不同。这里只用来比较 critic 的设置，不受影响。

### 5.2 指标

同 Qwen3.5 预实验 §5.2：EV 直接调用验证报告用的函数，分 Airline、Retail、总体报告，同时报告偏移；AUC 用每条轨迹 action token
预测的平均值排序；区间按题分组 bootstrap 2 万次，比较两个设置时用配对 bootstrap。

### 5.3 超参数选择

ridge 正则系数、模拟中的"最优 lr"只在训练数据上选：按题分组 5 折交叉验证。不允许用验证集选。

### 5.4 随机性

种子 20261015。打乱顺序的模拟设置跑 3 个种子，报告均值和范围；复现 480 的设置按 480 的实际顺序，只跑一次。

## 6. 实验步骤

### E1 特征提取（GPU）

| 设置             | 值                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| 骨干网络         | 原始 Qwen3-4B-Instruct；480 第 94 步 critic 的骨干网络（只取最后一层，供 E7）                                |
| 层               | 最后一层（value head 的实际输入，需有测试证明逐元素一致）+ 第 9、18、27 层                                   |
| 训练轨迹的 token | 每条轨迹在 action token 中均匀抽 128 个（种子固定），不足 128 个全部保留；记录位置、轮次、题号、领域、reward |
| 验证轨迹的 token | 全部 action token                                                                                            |
| 精度             | bf16 存储                                                                                                    |

可以在 8 张卡上按轨迹分片并行，合并后校验条数与清单一致。开始前写出时间和磁盘估计。

### E2 闭式探针（检验 Q1）

同 Qwen3.5 预实验 E2：最后一层特征上的 ridge 回归（共用一个探针为主，分领域为参考）和逻辑回归探针，报告验证 EV、AUC、偏移、区间和探针权重的范数。

### E3 只训 head 的 Adam 模拟（检验 Q2、Q3）

| 设置    | 值                                                                                       |
| ------- | ---------------------------------------------------------------------------------------- |
| 数据    | 480 的 1494 条，每步 16 条，94 步                                                        |
| 顺序    | 复现 480（Q2）：480 的实际 batch 顺序；其余：每个 epoch 整体打乱                         |
| 损失    | 与训练器相同的 token 级 MSE 和加权方式                                                   |
| 初始化  | 复现 480（Q2）：480 初始 critic 的 head（权重和 bias 原样读出）；其余：$w=0$，$b=0.6205$ |
| head lr | 5e-6、2e-5、1e-4、3e-4、1e-3                                                             |
| 步数    | 94，每 5 步和最后一步在验证集上评估                                                      |

先跑复现 480 的设置判定 Q2。Q2 不成立时，后面的模拟结果只作参考，结论里写明。Qwen3.5 的 E3 显示 bias 是否固定、是否 warmup
几乎没有差别，这里不再扫这两项。

### E7 特征的层和位置（检验 Q4、Q5）

1. 对 E1 的每一层做 E2 的 ridge 探针，比较验证 EV（Q4）。
1. 用 480 第 94 步骨干网络的最后一层特征做同样的探针，与原始模型比较（Q5）。
1. 按位置分组报告最后一层探针的 EV：第一个 action token；轨迹进度 0–20%、…、80–100%（进度定义同 Qwen3.5 预实验偏离第 6 条）。
