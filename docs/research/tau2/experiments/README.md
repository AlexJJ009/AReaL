# 实验记录

每个实验一份，文件名 `YYYY-MM-DD-<slug>.md`，按实验记录本的方式写：

1. 目的：要回答的问题。
1. 预先登记的假设：跑之前写下，结果出来后不改。
1. 设置：代码版本、数据、模型、超参、资源。
1. 运行记录：任务 ID、时间、异常和处理。
1. 结果：数字、图表和对假设的判断。

长期有效的决策写到 [../decisions/](../decisions/README.md)，不放在这里。
